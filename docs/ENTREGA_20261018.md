## Respuestas para la presentación

- Si hay discrepancia o ambigüedad reconocida entre lecturas, Oli se abstiene de autorizar. Dos lectores y cero fallos observados no garantizan exactitud universal.
- Si cambia el mandato, una solicitud obsoleta se rechaza. La reevaluación aplica las reglas vigentes a la lectura guardada y conserva el historial.
- Si llega el mismo archivo o el mismo número de proveedor, se frena el duplicado. Un antecedente con identidad sin resolver requiere aclaración y no abre una excepción humana genérica.
- Si falla un proveedor, hay intentos acotados. El agotamiento queda como fallo técnico, sin decisión de autorización ni reserva. La lectura nativa PDF evita la dependencia del parser que se saturó durante las pruebas.
